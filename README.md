# Real-Time Analytics Dashboard for Data Streams

> **Machine Learning Methods for Data Streams**
> **Author:** Bartosz Szymański 

## Overview
This project introduces the `StreamDashboard` class - a general-purpose, real-time 8-panel analytics dashboard designed for monitoring machine learning models in non-stationary environments. Inspired by the concept drift taxonomy proposed by Webb et al. (2018), the dashboard provides deep, simultaneous diagnostics of stream behavior and model adaptation.
